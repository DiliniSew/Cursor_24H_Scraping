# Sri Lankan Tourism Scraping Knowledgebase

This repository is a scraping knowledgebase built for a hackathon.

It contains data and references focused on Sri Lankan tourism, intended to support scraping, organization, and reuse of tourism-related information.

## Purpose

- Collect Sri Lankan tourism data from relevant sources.
- Organize the scraped information into a reusable knowledgebase.
- Support hackathon experiments, prototypes, and demos.

## Scope

The knowledgebase may include tourism topics such as:

- Destinations and attractions
- Hotels and accommodation
- Transport and travel routes
- Local experiences and activities
- Cultural and historical sites
